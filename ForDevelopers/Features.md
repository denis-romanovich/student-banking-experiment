#### Features

```txt
1. Авторизация и аутентификация
   1.1. Логин и пароль
       1.1.1. Вход по логину/паролю (JWT для API, Cookie для BFF)
       1.1.2. Регистрация нового пользователя
       1.1.3. Восстановление пароля
       1.1.4. Refresh Token (продление сессии)
       1.1.5. Блокировка после N неудачных попыток
       1.1.6  Вход по ЭЦП
   1.3. 2-факторная аутентификация (TOTP)
       1.3.1. Включение/отключение 2FA
   1.4. Электронная подпись (ЭЦП)
       1.4.1. Подписание документа
       1.4.2. Проверка подписи
       1.4.3. Снятие подписи
       1.4.4. Поддержка форматов:
           1.4.4.1. Россия (ГОСТ Р 34.10-2012 / КЭП)
           1.4.4.2. Беларусь (ГОСТ РБ 34.10-2012)
           1.4.4.3. EU (eIDAS, XMLdsig, PAdES)
           1.4.4.4. USA (PAdES / CAdES)
   1.5. Сервис нотификаций (уведомления)
       1.5.1. Email уведомления
       1.5.2. SMS уведомления (опционально)
       1.5.3. Push-уведомления в браузере
   1.6. Выход и безопасность
       1.6.1. Logout
       1.6.2. Выход из всех устройств
       1.6.3. История входов

2. Поддержка нескольких языков
   2.1. Русский язык (RU)
   2.2. Английский язык (EN)
   2.3. Автоопределение по заголовку Accept-Language
   2.4. Переключатель языка в UI
   2.5. Хранение выбранного языка в профиле
   2.6. Локализация дат, валют, чисел

3. Виджеты рабочего стола
   3.1. Счета и карточки
       3.1.1. Список счетов с остатками
       3.1.2. Карточки (дебетовые/кредитные)
       3.1.3. Быстрый перевод по карте/счёту
   3.2. Курсы валют
       3.2.1. Текущие курсы (API ЦБ РФ / OpenExchangeRates)
       3.2.2. График изменения курса
       3.2.3. Конвертер валют
   3.3. Календарь событий
       3.3.1. Предстоящие платежи
       3.3.2. Сроки подписания документов
       3.3.3. Напоминания

4. Раздел документы
   4.1. Типы документов
       4.1.1. Платёжное поручение
   4.2. Действия с документами
       4.2.1. Новый документ
       4.2.2. Копия документа
       4.2.3. Изменить документ (только до подписания)
       4.2.4. Подписание документа (вызов ЭЦП)
       4.2.5. Снятие подписи
       4.2.6. Отправка документа
       4.2.7. Удаление документа
       4.2.8. Печать документа (PDF)
       4.2.9. Экспорт
   4.3. Статусная модель документа
       4.3.1. Подписан
       4.3.2. Отправлен
       4.3.3. Исполнен
       4.3.4. Отклонён
   4.5. Список документов
       4.5.1. Пагинация
       4.5.2. Фильтрация (по дате, статусу, контрагенту)
       4.5.3. Поиск (по номеру, сумме)
       4.5.4. Массовые операции (подписать несколько)

5. Справочники
   5.1. Валюты (код, название, курс)
   5.2. Страны (наименование, код)
   5.3. Контрагенты (название, ИНН, КПП, счёт)
   5.4. Банки (БИК, название, корр. счёт)

6. Зоны доступности
   6.1. Неавторизованная зона
       6.1.1. Новости и публичная информация
       6.1.2. Форма входа
       6.1.3. Восстановление пароля
       6.1.4. Регистрация
       6.1.5. Публичная страница статуса документа (по номеру)
   6.2. Авторизованная зона
       6.2.1. Рабочий стол с виджетами
       6.2.2. Раздел документов
       6.2.3. Счета и карточки
       6.2.4. Сообщения от банка
       6.2.5. Настройки пользователя

7. Сообщения от банка
   7.1. Входящие сообщения
       7.1.1. Список сообщений
       7.1.2. Отметка о прочтении
       7.1.3. Важные сообщения (звездочка)
   7.2. Real-time уведомления (WebSockets)
       7.2.1. Новое сообщение
       7.2.2. Смена статуса документа
   7.3. Сервис отправки сообщений
       7.3.1. Фоновый сервис / микросервис
       7.3.2. Шаблоны сообщений

8. Счета и выписки
   8.1. Счета пользователя
       8.1.1. Список счетов
       8.1.2. Реквизиты счёта
       8.1.3. Блокировка/разблокировка счёта
   8.2. Выписка по счёту
       8.2.1. Движения за период
       8.2.2. Фильтрация по дате
       8.2.3. Выгрузка выписки (PDF, Excel)

9. Настройки пользователя (кабинет)
   9.1. Профиль
       9.1.1. ФИО, контакты
       9.1.2. Аватар
   9.2. Безопасность
       9.2.1. Смена пароля
       9.2.2. Настройка 2FA
       9.2.3. Сертификат ЭЦП по умолчанию
   9.3. Интерфейс
       9.3.1. Выбор языка (RU/EN)
       9.3.2. Настройка виджетов (порядок, отображение)
       9.3.3. Тёмная/светлая тема
   9.4. Уведомления
       9.4.1. На какие события присылать уведомления
       9.4.2. Способ доставки (Email / SMS / Push)

10. Сервис обработчик документов (отдельный микросервис)
    10.1. Генерация PDF
        10.1.1. Платёжное поручение
        10.1.2. Выписка
        10.1.3. Акт сверки
    10.2. Конвертация форматов
        10.2.1. XML (формат банка РФ)
        10.2.2. JSON (для API)
        10.2.3. 1C (обмен с бухгалтерией)
    10.3. Валидация документов
        10.3.1. Проверка реквизитов (ИНН, КПП, БИК)
        10.3.2. Валидация по форматам (РФ, РБ, EU, USA)
    10.4. Очередь обработки (RabbitMQ / Hangfire)
        10.4.1. Асинхронная обработка
        10.4.2. Повторная попытка при ошибке

11. Дополнительные фичи
    11.1. Дашборд с графиками
        11.1.1. Обороты по счетам
        11.1.2. Статусы документов
```
