#### Стек
Backend: ASP.NET Core 8 + EF Core + PostgreSQL + JWT |
BFF + Frontend: HTML + CSS + Vanilla JS (внутри Razor) | 
Admin: React + Ant Design + React Router

Фронтенды отличаются, чтобы разнообразить обучение.
По желанию можно будет добавлять любой стек.
Выделяя его в отдельный микросервис если в этом есть смысл.

### Backend for Frontend (BFF) — Razor Pages

| Компонент                | Технология                                  | Версия | Назначение                            |
| ------------------------ | ------------------------------------------- | ------ | ------------------------------------- |
| **Фреймворк**            | [ASP.NET](https://ASP.NET) Core Razor Pages | 8+     | Серверный рендеринг HTML-страниц      |
| **Шаблонизация**         | Razor Syntax (cshtml)                       | —      | Встраивание C# кода в HTML            |
| **Тег-хелперы**          | Встроенные + кастомные                      | —      | Упрощение работы с формами и ссылками |

### Клиентский Frontend (внутри Razor Pages)

| Компонент                | Технология                    | Назначение                                 |
| ------------------------ | ----------------------------- | ------------------------------------------ |
| **Разметка**             | HTML5 + Razor Syntax          | Структура страниц с серверными данными     |
| **Стили**                | CSS3 + CSS Variables          | Адаптивный дизайн, кастомные стили         |
| **Язык**                 | Vanilla JavaScript (ES6+)     | Клиентская интерактивность                 |
| **HTTP-клиент**          | Fetch API                     | AJAX-запросы к Main API из браузера        |
| **Работа с DOM**         | Нативные методы               | querySelector, addEventListener, classList |
| **Хранение данных**      | localStorage / sessionStorage | JWT токены, состояние корзины              |
| **Модули**               | ES Modules                    | Разделение кода на модули                  |
| **Сборка (опционально)** | Vite                          | (рекомендуется) Сборка JS и CSS модулей    |
| **Библиотеки**           | Bootstrap / Tailwind          | (опционально) Ускорение вёрстки            |

| Компонент            | Технология                              | Версия     | Назначение                                                 |
| -------------------- | --------------------------------------- | ---------- | ---------------------------------------------------------- |
| **Язык**             | C#                                      | .NET 8+    | Основной язык разработки                                   |
