#### Схема
Первоначальная, на данный момент не учитывает появление других сервисов
```
┌─────────────────────────────────────────────────────────────────┐
│                        ПОЛЬЗОВАТЕЛЬ                              │
└─────────────────────────────────────────────────────────────────┘
          │                              │
          ▼                              ▼
┌─────────────────────┐        ┌─────────────────────────────────┐
│   React Admin       │        │   BFF (Razor Pages)             │

│   SPA для админов   │        │   • HTML (серверный рендеринг)  │

│   React Router      │        └───────────────┬─────────────────┘
└──────────┬──────────┘                        │
           │                                    │
           │ JWT                                │ Внутренний HTTP
           │ (напрямую)                         │ (HttpClient)
           │                                    │
           ▼                                    ▼
┌─────────────────────────────────────────────────────────────────┐
│                    MAIN API                                     │
│                    ASP.NET Core + EF Core                       │
│                                                                 │
│   • Все CRUD операции                                            │
│   • Бизнес-логика                                                │
│   • JWT аутентификация (выдача и проверка)                       │
│   • Работа с PostgreSQL                                          │
```
